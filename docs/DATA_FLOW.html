1. The big picture

Dashed bands are the three phases. Red boxes are the only places the network is touched; in the per-request band only OSRM is hit in the normal case, and Nominatim only when a place is not in the local gazetteer (for example a street address).

2. Offline pipeline: turning the CSV into something routable

The CSV has no coordinates, and its addresses are highway exits that free geocoders cannot resolve. So stations are placed at the centre of their city, once, offline, and the result is committed.

A

GeoNames US postal places manage.py build_gazetteer

GeoNamesus_places.json

Downloads US.zip (postal-code places with lat/lon) to .cache/geonames/, normalises city names, keeps one centroid per (city, state), and exports fuel/data/us_places.json: 29,542 places plus a state-name → code table. Committed, so a fresh clone needs no download.

B

Geocode the CSV's cities manage.py geocode_places

fuel-prices.csvgazetteer.lookup_placeNominatim (fallback, 1 req/s)geocoded_places.json

Reads the 3,898 distinct (city, state) pairs in the CSV. Each is looked up in the GeoNames index first; misses go to Nominatim with a custom User-Agent at one request per second. Output: fuel/data/geocoded_places.json, 3,897 pairs with source = geonames or nominatim.

The single miss is "Pass Lake, ON" (Flying J #866, CSV rows 4949–4954), a Canadian hamlet. 85 of the pairs are Canadian; they are kept but never used as stops.

D

In-memory station index gazetteer.get_station_index()

numpy arrays in RAM

On the first request the process loads every station that has a place and a US state code into four parallel numpy arrays: ids, lats, lons, prices. 7,403 stations. Loaded once per process, so the corridor search never queries SQLite.

4. Per request: GET /api/route/?start=New York, NY&finish=Los Angeles, CA

1

Validate fuel/api/views.py · RouteView · RouteQuerySerializer

DRF

GET query params or POST JSON body. Checks ranges: corridor_miles 0.5–100, initial_fuel_gallons 0–tank, mpg 1–100, range_miles 10–2000, min_stop_savings_usd 0–1000, geometry simplified|full|none. Bad input → 400 invalid_request.

2

Orchestrate fuel/services/trip.py · plan_trip()

triphttp.external_calls counter

Resets the per-request external-call counter (a ContextVar in http.py; every real HTTP call increments it). Then runs steps 3–8 in order and times routing vs compute.

3

Resolve start and finish geocoding.resolve_location(text) ×2

geocodingPlace tableus_places.jsonNominatim (fallback only)
  1. "40.71,-74.00" → parsed directly. 0 calls.
  2. "City, ST", "City ST", "City, State Name" → Place table, then GeoNames index. 0 calls. Inputs ending in a Canadian province code are rejected before any call.
  3. Anything else (street address, bare "Paris") → Nominatim, one call per location. The best match must have country_code us, else 400 outside_usa naming the country found.

Every result passes assert_inside_usa (bounding boxes for the lower 48, Alaska, Hawaii). Output: Location(lat, lon, label, source).

4

Get the driving route routing.get_route(start, finish)

OSRM demo serverDjango LocMem cache, 24 h

Cache key = route:v1: + coordinates rounded to 4 dp. On a miss: one GET to router.project-osrm.org/route/v1/driving/{lon,lat};{lon,lat}?overview=full&geometries=geojson, 10 s timeout, one retry on timeout/5xx. Parses distance (m → miles), duration (s → hours) and the GeoJSON LineString (about 11,000 points for NYC → LA). Failures → 502 upstream; OSRM "NoRoute" (e.g. Honolulu) → 422 no_route.

Output: Route(distance_miles=2799, duration_hours, coordinates[(lon,lat)], provider="osrm", cached). This is the only network call in the normal case; the second identical request reads the cache and reports external_calls: 0.

5

Find stations near the road corridor.find_candidates(coords, StationIndex, corridor_miles)

corridor (pure numpy)StationIndex
  • Cumulative mile markers along the polyline (haversine per segment).
  • Resample the route every mile, so long straight highway segments still have samples.
  • Project all 7,403 stations with an equirectangular projection (cos of the sample latitude), compute the nearest sample for each station in chunks, then project onto the actual road segment.
  • Keep stations within corridor_miles (default 10). Output: sorted Candidate(position_miles, price, station_id, detour_miles), about 300 for NYC → LA, in ~15 ms.

Positions are then scaled by route.distance_miles / polyline_miles so mile markers match OSRM's road distance.

6

Choose where to buy fuel planner.plan_stops(candidates, route_miles, PlannerConfig)

planner (pure Python)

Greedy gas-station algorithm, proven optimal on a line and tested against a brute-force DP:

  1. Coast on the initial fuel (default full tank, 50 gal) to the cheapest reachable station. If the initial fuel cannot reach any station, raise it to the minimum needed and add a warning.
  2. At each station: if a cheaper station is within range, buy just enough to reach it. Else if the finish is within a full tank, buy just enough to arrive empty. Else fill up and go to the cheapest station in range. Detours cost 2 × detour miles of fuel.
  3. No station in range → 422 unreachable with the gap in miles.
  4. Post-pass: merge any stop that saves less than min_stop_savings_usd ($5) into the previous one. NYC → LA: 17 stops → 13, cost rises a few dollars.

Output: Plan(stops, total_gallons, total_cost_usd=717.31, fuel_at_finish, warnings, merged_stops).

7

Hydrate the chosen stations FuelStation.objects.select_related("place").in_bulk(ids)

SQLite

One query for the 13 chosen station ids, with name, address, city, state and coordinates. SQLite is touched only here per request.

8

Shrink the geometry geometry.simplify(coords, 0.0005°)

geometry (numpy Douglas-Peucker)

Planning always uses the full OSRM line; the response gets the simplified one (default), the full one, or none. 11,000 points → about 1,100; 742 KB → 59 KB. Visually identical at map zoom.

9

Serialize serializers.build_route_payload() · errors via errors.describe_exception()

DRF response

Rounds gallons to 0.01 and money to cents, builds map_url, and adds meta: external_calls, cached_route, candidate_stations, geometry_points, routing_ms, compute_ms. Any typed service error becomes {"error": {code, message, details}} with 400 / 422 / 502.

10

Map page GET /api/route/map/?start=…&finish=… · RouteMapView · templates/fuel/map.html

Django templateOSM tiles (browser only)

Runs the same plan_trip (route comes from the cache, so 0 server-side external calls), embeds the payload with json_script, and Leaflet 1.9.4 draws the polyline, start/finish, numbered stop markers with popups, and a summary panel. Map tiles are fetched by the browser from OpenStreetMap; the server never calls a tile or static-map API.
